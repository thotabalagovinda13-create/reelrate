# ReelRate

A responsive movie discovery and personal ratings app powered by TMDB.

## Deploy
Import this GitHub repository at https://vercel.com/new and add `TMDB_ACCESS_TOKEN` as a Vercel Environment Variable (use your TMDB API Read Access Token). Redeploy after adding it.

The app supports popular, trending, top-rated, now-playing, upcoming, search, genre/year filters, movie details, personal 1–10 ratings, watchlists and genre-based recommendations. Catalogue results are paginated; use search/discovery to explore TMDB's catalogue.

Ratings and watchlists are stored in the visitor's browser. TMDB attribution is included in the footer. Review TMDB's API terms before public/commercial use.
